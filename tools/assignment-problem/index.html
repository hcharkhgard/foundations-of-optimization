Assignment problem interactive tool: Hungarian Method

Assign every assignee to exactly one task (and every task to exactly one assignee) at the smallest total cost. Enter a cost table, see it written as a linear program (the integrality condition can be dropped), then solve it step by step with the Hungarian method: row and column reductions, the minimum number of lines through all zeros, adjustments, and the final assignment.

3 · The Hungarian method

Press Next in the bar at the bottom (or →) to take one step, Back (←) to undo it, or ▶ Play to watch it run.

4 · At a glance

Preparing the table

  1. Not allowed (assignee i cannot do task j): cost M, a very large number (in the LP: xij = 0).
  2. Required (assignee i must do task j): the pair is decided, so delete row i and column j and solve the smaller problem; add cij back at the end.
  3. Not square: add dummy rows or columns with cost 0 until the table is square. A dummy assignment means “left unassigned”.

The Hungarian method

  1. Subtract each row minimum from its row, then each column minimum from its column.
  2. Cover all zeros with the minimum number of lines (rows or columns).
  3. If the number of lines is n: an optimal assignment uses only zeros. Start with a row or column that has a single zero.
  4. Otherwise let k = the smallest uncovered number: subtract k from every uncovered entry, add k to every entry covered by two lines, and go back to step 2.
