The four rules

Rules 1 and 2 touch only the objective. Rules 3 and 4 may be applied in any order and to the rows and variables in any order — substitution is linear, so the moves never interfere.

R1

Make the objective a maximization

min f(x) = −max (−f(x))

If the problem minimizes
minn∑j=1cjxj
⟶

Multiplying by −1 reverses the ranking of every feasible point, so the maximizer of −f is exactly the minimizer of f. The optimal solution is untouched; only the optimal value flips sign: z*min = −w*max.

R2

Drop the constant from the objective

A shift of every value cannot change which point wins.

If a constant is present
maxn∑j=1cjxj + c0
⟶
maxn∑j=1cjxj

The feasible region never mentions c0, and every feasible point gains the same c0, so the argmax is identical. Solve without it and add it back at the end. Applied after R1, the constant you drop is already the sign-flipped one — the worksheet keeps that bookkeeping for you.

Each ≤ row and each ≥ row picks up one new nonnegative variable, so the reduction adds m1 + m3 slacks. The number of rows never changes: m′ = m. Slack variables enter the objective with coefficient 0.

The flipped row leaves −bi on the right, which may well be negative. That is fine — standard form places no sign condition on b̄.

Any real number is the difference of two nonnegative numbers, so the split loses nothing. At any basic feasible solution at most one of x′j, x″j is positive, and the honest reading is x′j = max(xj, 0), x″j = max(−xj, 0).

Slack variables created in R3 are already nonnegative and need nothing here.

Fine print worth saying out loud in class

  1. Standard form does not require b̄ ≥ 0. Flipping a ≥ row routinely produces a negative right-hand side. The extra requirement b ≥ 0 belongs to the setup for Phase I of the simplex method, not to standard form itself.
  2. Slack and surplus are the same variable here. Writing ∑aijxj − ei = bi for a ≥ row and multiplying through by −1 gives exactly the equation R3 produces, with si = ei. Flip-then-slack and subtract-a-surplus are two names for one move.
  3. Order does not matter. You can slack row 3 before row 1, split a free variable before flipping the objective, and land on the same standard form. Try it in the worksheet — the moves commute.
  4. Multiplying a ≤ row by −1 is legal but unhelpful. The worksheet lets you do it so the mistake is visible: the row becomes ≥ and you have to flip it back before a slack will go on.
  5. The free-variable split is not unique. Adding the same constant to x′j and x″j leaves xj unchanged, so the standard form has a whole ray of optimal solutions where the general form had one point. The simplex method never sees this: a basic solution keeps at most one of the pair in the basis.
  6. An unrestricted variable can be eliminated instead of split. If xj is free and appears in some equation, solve that equation for it and substitute it out — one fewer variable and one fewer row, rather than one more variable. The split is the mechanical route; elimination is the economical one.
  7. Feasibility and unboundedness are preserved. Every rule is a bijection between the two feasible sets that respects the objective up to the recorded sign and shift, so an infeasible problem stays infeasible and an unbounded one stays unbounded.
