# Graphical Solution Method – Linear Programming

An interactive teaching tool for solving two-variable linear programming problems with the graphical method.

**Open the tool:** https://hcharkhgard.github.io/foundations-of-optimization/tools/graphical-solution-method/

## What it does

1. **Constraints** – convert each constraint to an equality, choose two points on the line, draw it, and pick the feasible side (checked with a test point).
2. **Region** – switch constraints on and off to build the feasible region step by step.
3. **Objective** – draw two objective lines, identify the direction of improvement, then move the line parallel to itself to the optimum.
4. **Solve** – pick any two lines and solve the system of equations by substitution, step by step, then check feasibility and compute Z at the point.

Includes examples for maximization, minimization, multiple optimal solutions, unbounded and infeasible problems.

## Use

Open `index.html` in any browser, or visit the GitHub Pages link above. No installation needed.
