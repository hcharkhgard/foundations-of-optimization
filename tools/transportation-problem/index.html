Transportation problem interactive tool: Transportation Simplex Method

Ship goods from sources (each with a supply) to destinations (each with a demand) at the smallest total cost. Enter a cost table, see it as a linear program together with its dual (that is where ui, vj and the test ui + vj − cij come from), then solve it with the transportation simplex method: balance, northwest rule, dual values, the entering cell, the loop, and the new solution.

4 · At a glance

Special cases

  1. Not balanced: supply > demand → add a dummy destination; demand > supply → add a dummy source. Dummy costs are 0. Shipping to a dummy destination = supply left unused; from a dummy source = demand left unmet.
  2. Route not possible: cost M, a very large number (in the LP: xij = 0).
  3. Minimum shipment xij ≥ L: ship L first, lower si and dj by L, solve the rest, and add L back.
  4. Degeneracy: a basic solution always has m + n − 1 basic cells; some may ship 0.

The transportation simplex method

  1. Step 1. Balance the problem.
  2. Step 2. Northwest rule for an initial basic feasible solution.
  3. Step 3. u1 = 0 and ui + vj = cij for every basic cell.
  4. Step 4. If ui + vj − cij ≤ 0 for every non-basic cell: optimal. Otherwise the most positive one enters; find its loop, θ = the smallest amount on a “−” cell, which leaves. Add θ on “+” cells, subtract on “−” cells.
  5. Step 5. Repeat Steps 3 and 4.
