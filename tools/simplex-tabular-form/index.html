Simplex method interactive tool: Tabular Form

Pick an example or type your own linear program. Then run the simplex method on a simplex tableau, one move at a time: standardize, check that the origin is feasible, build the initial tableau, and in every iteration choose the pivot column (reduced costs), the pivot row (minimum ratio test), and watch the row operations that build the next tableau.

1 · The problem

All decision variables are assumed nonnegative. For the origin to be feasible, every constraint must be ≤ with a nonnegative right-hand side. Coefficients accept integers, decimals or fractions such as 3, −1.5, 2/7. Arithmetic is exact.

3 · The procedure at a glance

Preparing to run the simplex method

  1. Step 1. Transform the problem into standard form, with a maximization objective. Each ≤ constraint gets its own slack variable.
  2. Step 2. Check that the origin is feasible: every constraint is ≤ and every right-hand side is nonnegative.
  3. Step 3. Write row (0) as z − c1x1 − … − cnxn = 0 and build the initial tableau: columns Basic, Eq., z, one column per variable, and RHS; one row per equation.

Each iteration on the tableau

  1. Step 1. Basic variables and the new tableau. Initially the slacks are basic. Later the entering variable replaces the leaving one in the Basic column, and row operations turn its column into a unit column: divide the pivot row by the pivot element, then add multiples of the pivot row to every other row (including row (0)) to make their entries 0. Read off the solution: basic variable = RHS of its row, non-basic = 0, z = RHS of row (0).
  2. Step 2. Optimality test. Look at row (0). If no non-basic variable has a negative coefficient (reduced cost), stop: optimal. Otherwise pick one (the most negative is the usual rule): it enters, and its column is the pivot column.
  3. Step 3. Minimum ratio test. For each row with a strictly positive pivot-column entry, divide its RHS by that entry; entries ≤ 0 are “impossible”. The smallest ratio marks the pivot row; its basic variable leaves. If every entry is ≤ 0, the problem is unbounded.
