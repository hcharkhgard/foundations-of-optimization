3 · The procedure at a glance

Preparing to run the simplex method

  1. Step 1. Transform the problem into standard form, with a maximization objective. Each ≤ constraint gets its own slack variable.
  2. Step 2. Check that the origin is feasible: every constraint is ≤ and every right-hand side is nonnegative.
  3. Step 3. If yes, start the simplex method with row (0): z − c1x1 − … − cnxn = 0. If not, a different starting trick is needed (not covered by this tool).

Each iteration

  1. Step 1. Initialization and Gaussian elimination. Decide which variables are basic and non-basic. Use row operations so each basic variable has coefficient 1 in its own row and 0 in every other row, including row (0). Then non-basic variables are 0 and each basic variable equals its right-hand side.
  2. Step 2. Optimality test. Is there a non-basic variable with a negative reduced cost (coefficient in row (0))? If no, the current basic feasible solution is optimal. If yes, choose one (the most negative is the usual rule) to enter the basis.
  3. Step 3. Next basic feasible solution. Keep the other non-basic variables at 0 and increase the entering variable. The minimum ratio test says which basic variable hits 0 first; it leaves the basis.
